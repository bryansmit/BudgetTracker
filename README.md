# BudgetTracker

This application represents a simple budget tracker with basic functionality like:
 
- Adding a transaction (**income** or **expense**). 
- Listing all transactions.
- Calculating the balance.

> This project is for learning the Java language and getting a better foundation on OOP/design patterns.
